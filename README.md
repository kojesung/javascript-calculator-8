# 미션 - 문자열 덧셈 계산기

## 입력 처리

-   [x] 사용자로부터 문자열 입력받기
    -   `Console.readLineAsync()`를 활용하여 구분자와 양수로 구성된 문자열을 입력받는다.

## 문자열 파싱

-   [x] 빈 문자열 처리
    -   빈 문자열을 입력받았을 땐 `[]`을 반환하여 합계가 0이 되도록 처리한다.
-   [x] 커스텀 구분자 추출
    -   `//`와 `\n` 사이에 커스텀 구분자가 있는 형태의 문자열인지 확인한다.
-   [x] 구분자에 따라 문자열에서 숫자 추출
    -   커스텀 구분자가 있을 경우엔 커스텀 구분자를 기준으로 분리하여 숫자 문자열을 추출한다.
    -   커스텀 구분자가 없을 경우엔 `,`와 `:`를 기준으로 분리하여 숫자 문자열을 추출한다.

## 숫자 추출

-   [x] 추출된 숫자 문자열을 숫자로 변환
    -   문자열 자료형인 숫자를 정수형으로 변경하여 연산할 수 있도록 변경한다.

## 계산

-   [x] 추출된 숫자들의 합 계산
    -   모든 숫자들을 더하여 결과를 반환한다.
    -   빈 배열의 경우 `0`을 반환한다.

## 출력

-   [ ] 계산기 결과 출력
    -   `Console.print()`를 활용하여 `결과 : ${result}` 형태로 출력한다.

## 예외처리

-   [ ] 잘못된 입력에 대한 검증
    -   사용자 입력에 음수가 포함된 경우 "[ERROR] 음수는 입력할 수 없습니다." 라는 메시지와 함께 `Error`를 발생시킨 후 애플리케이션을 종료한다.
    -   사용자 입력에 구분자 외에 숫자가 아닌 값이 포함된 경우 "[ERROR] 숫자가 아닌 값이 포함되어 있습니다." 라는 메시지와 함께 `Error`를 발생시킨 후 애플리케이션을 종료한다.
